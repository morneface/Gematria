Gematria Calculator

What this experimental site is for — in short

Gematria is the old habit of reading numbers hidden inside words: every letter is worth something, and the total is the « value » of the word. This site is a small laboratory built on that idea, and everything happens in this single page — it works offline.

  • Calculate a word or a number in three systems at once — Jewish/Hebrew, English (×6) and Simple (A=1 … Z=26) — with the letter-by-letter breakdown.
  • Explore ranges of numbers as 3×3 tables, translated into words, digits and Alpha Code.
  • Sort the 2048 BIP39 words into a numeric vocabulary of 9 roots, and spot the ones that keep landing on 3, 6 or 9.
  • Rewrite a whole text: each word is swapped for a phrase carrying the exact same value, so the numbers survive while the story changes.
  • Reproduce anything: each run mints a hash — paste it back to recover the very same result.

It is a playground, not a reference tool. Nothing here is validated against any historical or religious source, and BIP39 is used strictly as a word bank: no seed phrase is ever generated, checked or exposed.

Number Tables — 3×3 Grid

Range is split into 9 slices. Columns: number in words · number · Alpha Code (0→J, 1→A … 9→I) · digit sum · letter. Roots 33 66 99 are badged.

BIP39 × Alpha Code — Root Vocabulary

Each BIP39 word is converted to its Simple Gematria value (A=1 … Z=26), then that number is encoded in Alpha Code (0→J, 1→A … 9→I). For every word we compute the digit sum before reduction (e.g. 48 → 4+8=12) and the digital root after reduction (12 → 1+2=3) — a numeric vocabulary of 9 roots. Roots 33 66 99 are badged.

Word banks and offline use

BIP39 English (2048 words) is embedded in this page. French and Portuguese are downloaded from the official Bitcoin BIPs repository on first use; without a network they silently fall back to a built-in bank of 400 English words. English is therefore the only bank guaranteed to be identical online and offline.

Corpus Transformation — Words ➜ Phrases

Each word is converted to its SIMPLE gematria value (A=1 … Z=26), then replaced by a grammar-structured phrase with the exact same sum. Words become phrases — another story is written.

BIP39 banks load from the official Bitcoin BIPs repository when needed (English is embedded).



Every transformation mints a unique hash. Paste it back and click « Regenerate from hash » to recover the exact same phrases — unimaginably many possible generations, one string to find them again.

Offline behaviour — what still reproduces without a network
  • The hash is 100% local. The string is hashed (xmur3) into a seed that drives a seeded PRNG (mulberry32). No server, no Web Crypto, no network. The same hash always rebuilds the same phrases, order included.
  • Only the word bank needs the network. Built-in and BIP39 English (2048 words) are embedded in this file: offline they behave exactly the same.
  • BIP39 French and BIP39 Portuguese are downloaded from the official Bitcoin BIPs repository on first use. Offline the loader silently falls back to a built-in bank of 400 English words.
  • Consequence: with an FR/PT bank, the very same hash will not give back the same phrases if you switch between online and offline — the word pool changed, not the hash. The status line next to the selector always names the bank actually in use.
  • For strict reproducibility stay on Built-in or BIP39 English, or load the FR/PT bank once while online so the browser cache can serve it afterwards.
